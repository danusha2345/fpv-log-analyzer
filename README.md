# FPV Log Analyzer

Анализатор blackbox-логов FPV-дронов: помогает по графикам найти причину
проблемы — шум, фильтры, отклик, моторы. Не автотюнер. Linux и Windows.

Читает логи Betaflight (3.x, 4.x, 2025.x, 2026.x), INAV, EmuFlight и Rotorflight,
в том числе с нестандартными полями: поля берутся по именам из заголовка лога.

## Запуск

```bash
cargo run --release -- путь/к/логу.bbl
```

Лог можно также перетащить в окно или открыть кнопкой «Открыть лог…».

## Вкладки

| Вкладка | Что показывает |
|---|---|
| Обзор | Автоматические находки, вклад P/I/D/F по осям, события лога |
| Кривые | Сигналы во времени по Roll / Pitch / Yaw; масштаб по времени задаёт участок для остального анализа |
| Спектр | Шум до и после фильтров, частоты фильтров из лога, задержка фильтров, пробный фильтр |
| Карта шума | Шум в зависимости от газа или оборотов моторов |
| Спектрограмма | Шум во времени |
| Отклик | Отклик на ступеньку, усиление и фаза контура |
| Ошибка | Распределение ошибки слежения и её зависимость от скорости стиков |
| Моторы | Загрузка, насыщение и спектр выходов моторов |
| Настройки | Параметры из заголовка лога; при сравнении — отличия двух логов |

«Сравнить с…» накладывает второй лог штриховыми линиями на спектр и отклик.
«Сохранить снимок» пишет PNG текущей вкладки рядом с логом.

## Без окна

```bash
fpv-log-analyzer лог.bbl report          # находки текстом
fpv-log-analyzer лог.bbl csv [номер]     # запись в CSV на стандартный вывод
fpv-log-analyzer лог.bbl response        # спектры, задержка, отклик и ЧХ таблицей
fpv-log-analyzer лог.bbl step+save       # снимок вкладки в PNG и выход
```

Имена вкладок для командной строки: `overview`, `curves`, `spectrum`, `heatmap`,
`spectrogram`, `step`, `error`, `motors`, `settings`. Третьим аргументом можно
передать лог для сравнения.

## Сборка под Windows

```bash
cargo build --release --target x86_64-pc-windows-gnu
```

Если на машине нет Vulkan / DirectX 12, окно откроется через OpenGL.

## Проверка

```bash
cargo test --release
python3 tools/compare_with_blackbox_decode.py папка_с_логами   # сверка разбора с blackbox_decode
python3 tools/crosscheck_scipy.py лог.bbl                      # сверка анализа со scipy
```

Состояние, план и известные слабые места — в [docs/TRACKER.md](docs/TRACKER.md).
